# Обозначения в статье Borodich, Gasnikov & Kovalev (2025)

*On Linear Convergence in Smooth Convex-Concave Bilinearly-Coupled Saddle-Point Optimization: Lower Bounds and Optimal Algorithms.*

Словарь охватывает основную часть, обе таблицы и приложения A–N. ВН означает «вариационное неравенство». Номера страниц соответствуют PDF. Индексы суммирования и локальные переменные объединены в строки по их роли. Одинаковые буквы с разным смыслом приведены в каждом соответствующем разделе.

## 2. Седловая задача, её параметры и решение (с. 1–5)

| Обозначение | Что означает | Где |
|---|---|---|
| $x\in\mathcal X=\mathbb R^{d_x}$ | Прямая переменная, по которой минимизируют. $d_x$ — её размерность. | (1) |
| $y\in\mathcal Y=\mathbb R^{d_y}$ | Двойственная переменная, по которой максимизируют. $d_y$ — её размерность. | (1) |
| $F(x,y)$ | Целевая функция седловой задачи: $f(x)+\langle y,Bx\rangle-g(y)$. | (1) |
| $f(x),g(y)$ | Гладкие выпуклые функции. Знак $-g(y)$ даёт вогнутую зависимость $F$ по $y$. | (1), допущения 2.3–2.4 |
| $B\in\mathbb R^{d_y\times d_x}$ | Матрица билинейной связи. $Bx$ принадлежит $\mathcal Y$, а $B^\top y$ — $\mathcal X$. | (1) |
| $\nabla f(x),\nabla g(y)$ | Градиенты двух функций и два отдельных типа оракульного вызова. | §1, §3.1 |
| $L_x,L_y$ | Константы гладкости $f,g$, то есть верхние оценки липшицевости их градиентов. | Допущения 2.3–2.4 |
| $\mu_x,\mu_y$ | Константы сильной выпуклости $f,g$. Значение 0 допускает выпуклую функцию без гарантии сильной выпуклости. | Допущения 2.3–2.4 |
| $L_{xy}$ | Верхняя оценка $\sigma_{\max}(B)$. В статье условие записано для квадрата: $L_{xy}^2\ge\lambda_{\max}(B^\top B)=\lambda_{\max}(BB^\top)$. | Допущение 2.5 |
| $\mu_{xy}$ | Спектральная нижняя оценка связи со стороны $x$. Если $\nabla f(x)\in\operatorname{range}B^\top$ для всех $x$, допускается $\mu_{xy}^2\le\lambda_{\min}^{+}(B^\top B)$. Иначе требуется $\mu_{xy}^2\le\lambda_{\min}(B^\top B)$. | Допущение 2.5 |
| $\mu_{yx}$ | Спектральная нижняя оценка связи со стороны $y$. Если $\nabla g(y)\in\operatorname{range}B$ для всех $y$, допускается $\mu_{yx}^2\le\lambda_{\min}^{+}(BB^\top)$. Иначе используется $\lambda_{\min}(BB^\top)$. Если обе оценки положительны, авторы требуют $\mu_{xy}=\mu_{yx}$. | Допущение 2.5 |
| $\pi,\Pi$ | $\pi=(L_x,L_y,L_{xy},\mu_x,\mu_y,\mu_{xy},\mu_{yx})$ — вектор параметров. $\Pi$ — множество допустимых таких векторов. | §2.1–2.2 |
| $\delta_x$ | $\mu_x+\mu_{xy}^2/L_y$. Константа квадратичного роста прямой цели относительно $\mathcal S_x$. | (4) |
| $\delta_y$ | $\mu_y+\mu_{yx}^2/L_x$. Константа квадратичного роста для $-D$ относительно $\mathcal S_y$. | (4) |
| $P(x)$ | Прямая целевая функция $f(x)+g^*(Bx)$, получаемая максимизацией $F(x,y)$ по $y$. | (5) |
| $D(y)$ | Двойственная целевая функция $-g(y)-f^*(-B^\top y)$, получаемая минимизацией $F(x,y)$ по $x$. | (5) |
| $P(x)-D(y)$ | Прямо-двойственный разрыв. В теореме 3.2 используется как один из критериев точности. | (5), (12) |
| $\kappa_x,\kappa_y,\kappa_{xy}$ | Числа обусловленности $L_x/\delta_x$, $L_y/\delta_y$ и $L_{xy}^2/(\delta_x\delta_y)$. При $\delta_x,\delta_y>0$ их квадратные корни определяют сложности по $\nabla f$, $\nabla g$ и матричным умножениям соответственно. | (6), (13), следствие 4.8 |
| $(x^*,y^*)$ | Седловое решение. Условия оптимальности: $\nabla f(x^*)+B^\top y^*=0$, $\nabla g(y^*)-Bx^*=0$. | (7) |
| $\mathcal S,\mathcal S_x,\mathcal S_y$ | Множество седловых решений $\mathcal S=\mathcal S_x\times\mathcal S_y$ и множества решений прямой и двойственной задач соответственно. | Лемма 2.8 |
| $x^*+\ker B,\ y^*+\ker B^\top$ | Аффинные множества прямых или двойственных решений при $\mu_x=0$ или $\mu_y=0$ соответственно, в условиях леммы 2.8. При положительной соответствующей $\mu$ множество состоит из одной точки. | (8) |
| $R^2_{\delta_x\delta_y}(x,y)$ | Взвешенный квадрат расстояния до решения: $\delta_x\operatorname{dist}^2(x;\mathcal S_x)+\delta_y\operatorname{dist}^2(y;\mathcal S_y)$. | (9) |

| $z_{\rm in},z_{\rm out}$ | Входная и выходная точки одного запуска. Для седловой задачи это пары $(x_{\rm in},y_{\rm in})$ и $(x_{\rm out},y_{\rm out})$. | Теоремы 4.5, 4.7 |

## 5. Псевдокод, анализ рекурсии и перезапуски (приложения B, K–N)

В обозначениях верхний индекс $k;t_1,\ldots,t_k$ кодирует уровень рекурсии и историю индексов. У итератов $z$ уровень стоит сверху, а история — снизу.

| Обозначение | Что означает | Где |
|---|---|---|
| $i,k,j,l,t,t_k$ | $i$ — номер компоненты, $k$ — глубина рекурсии, $j,l$ — служебные индексы произведений или уровней, $t_k$ — номер шага на уровне $k$, $t$ — общий индекс шага или перезапуска. | B, K–N |
| $T_i,T_k$ | Число итераций внутреннего цикла на указанном уровне. Произведение $\prod_{j=1}^iT_j$ считает посещения уровня $i$ за один запуск. | B, (21), (181) |
| $p_i^0(z),z^i_{0,\ldots,0}$ | Исходная копия функции $p_i$ и начальная точка уровня $i$, равная $z_{\rm in}$. | B, строки 3–5 |

## Замечания к чтению PDF

- В (20) напечатано условие $t\ge1$, хотя инициализация даёт только $\alpha_0$. Если применить ту же рекурсию с $t=0$, получается $\alpha_1=2/(1+\sqrt5)$, как следует из тождества в сноске 6 при $t=1$.
- В строках 21–22 псевдокода в градиенте виден символ $p_i^{k;t_1,\ldots,t_k}$, хотя модель с этим обозначением задаётся следующей строкой через $\Delta_k$. Доказательство K.1.1 при работе с этой линеаризацией использует $\nabla\widehat p_k^{k;t_1,\ldots,t_k}$. Шляпка различает преобразованную гладкую функцию и построенную из неё модель.
- В аннотации вкладов на с. 3 под знаками сложности приведены $\kappa_x,\kappa_y,\kappa_{xy}$ без корней. В формальных оценках (13) и следствии 4.8 стоят квадратные корни, а определения самих $\kappa$ даны в (6).
